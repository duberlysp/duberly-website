EXPLORAR EL ALMANAQUE

Un dispositivo para combinar conceptos, experimentar relaciones y producir una lectura propia.

El arte multiplica las posibilidades. Gira cada círculo como si tuvieras el objeto entre las manos: operación, medio, relación, proceso y fruto se reorganizan para abrir una configuración singular. La línea superior marca el encuentro actual.

Arrastra cualquier anillo con el mouse o con el dedo. Al soltar, el círculo encuentra la palabra más cercana a la guía. También puedes tocar una palabra para llevarla al encuentro.
